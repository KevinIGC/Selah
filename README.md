# Selah showcase

Spanish-first, responsive showcase for the in-development Christian social app Selah. Branding and feature direction are grounded in the SELAH project context and supplied app screenshots.

No build or dependencies required. Serve `dist/` with `python3 -m http.server 4173 --directory dist`.

Features: screenshot phone frames, animated hero, accessible interactive screenshot tabs, FAQ disclosures, native sharing or clipboard fallback, scroll reveals, and reduced-motion support. Original supplied images are retained in the parent folder; optimized website copies live in `dist/assets`.

There is no email collection, launch date, download link, or fabricated testimonial. App features are labeled as in development. Font loading falls back to local sans-serif fonts if Google Fonts is unavailable.
